# Approved Visual Baseline

状态：**已确认 / 默认继承**
确认日期：2026-08-14
来源样片：内部确认的 Open Design + HyperFrames A/B 样片（不随公共仓库分发）

这份规范是当前个人 IP 横屏口播线的默认视觉基线。后续新视频直接继承；只有用户明确提出修改时，才允许偏离。

## 固定视觉规则

- 真实人物 A-roll 是画面主体，保持原视频亮度和肤色；不得为了突出包装而整体压暗人物。
- 背景必须存在且与主题匹配：优先使用真实拍摄环境叠加克制的深海蓝、蓝灰或暖琥珀氛围。禁止纯黑画布、无意的大面积空场和孤立的黑色信息板。
- 不使用扫描线、移动横向扫描光条或类似“科技滤镜”装饰。
- 不使用全屏渐变擦除、强烈发光擦屏或突兀的炫技转场；优先干净切换或极轻的边界变化。
- 人物脸部、嘴部、字幕和真实素材内部文字必须保持清晰，任何卡片、截图、标注都不得覆盖。
- 每个场景保持一个主信息和一个辅助证据，避免重复卡片堆叠、频繁版式切换和无意义留白。
- 真实截图/录屏优先使用原始素材，不生成假 UI、假数据或虚构用户证据。
- 动效要服务于语义：可用节点脉冲、路线绘制、轻微轨道运动和呼吸感位移，但保持克制、可读。

## 默认技术组合

- Remotion：A-roll、真实录屏、字幕和全局时间线。
- HyperFrames：HTML/CSS/GSAP 信息层、标题、证据卡和轻量动效。
- FFmpeg：最终音频混音、响度整理和封装。

## 渲染前门禁

1. 先确认 A-roll 和实际音频时间线，再做视觉包装。
2. 先渲染 15–30 秒复杂样片，检查人物亮度、背景连续性、素材可读性和版式切换。
3. 抽查开头、每个场景边界和结尾关键帧：不得有纯黑/空场、扫描线、遮字、遮脸或突兀全屏转场。
4. HyperFrames `lint` 与 `check --no-contrast` 通过后，仍需进行人工关键帧验收。
5. 最终交付保留无 BGM 干净母版；主片仅在用户明确要求时覆盖。

## 变更规则

任何新视觉实验都应放在独立项目或独立子目录中先做 A/B 样片；未得到用户确认前，不得改写本基线，也不得覆盖已确认样片。
