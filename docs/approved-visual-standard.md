# 已批准视觉标准：Mobile-first Dynamic Talkhead

批准日期：2026-08-21
批准样片：内部确认的 20 秒样片（不随公共仓库分发）
批准成片：内部确认的样片输出（不随公共仓库分发）

这套标准作为后续横屏口播视频的默认起点。除非用户明确指定新方向，不得回退到密集信息框或一次性整体出现的静态版式。

## 冻结规则

1. 人物 A-roll 是主体，保持原始亮度；只允许局部蓝色底光，不使用整屏暗色蒙层。
2. 画面信息只保留一个主结论和一个辅助关系；详细解释交给口播和字幕。
3. 右上角使用透明悬浮语义字：胶囊状态标签 + 大标题 + 短横线 + 极短副标题。默认不使用整块矩形信息框、常驻雷达或密集 bullet。
4. 流程按 1 → 2 → 3 → 4 顺序出现，步骤间隔 0.30–0.60 秒；禁止所有信息同帧跳出。
5. 主标题 ≥ 60px、场景标题 ≥ 48px、副标题 ≥ 28px、关键标签 ≥ 20px；每次必须通过 390px 手机缩略图 QA。
6. 信息层、素材和字幕必须给人物脸部与肩部留出缓冲；遇到碰撞先改版式，不靠加深蒙层。
7. 柱状图、节点、箭头、范围线和主题切换必须是程序动画，不用静态图片假装动态。

## 使用方式

- 新项目先复制这套规则到项目 `DESIGN.md`，再根据口播语义选择具体结构和视觉隐喻。
- 每次交付保留 HyperFrames 源、HyperFrames 输出、Remotion 合成和手机缩略图 QA 的完整链路。
- 如果用户要求偏离标准，必须在项目 `USER_FEEDBACK_LOG.md` 登记例外原因，并重新做全量回归。
