# Personal IP Skill

## 适用场景

AI 创业日志、独立开发者记录、Build in Public、个人项目成长。

## 内容规则

- 强调真实过程、当前状态、遇到的问题和下一步。
- 结果必须有素材或记录支持；允许承认尚未验证。
- 固定叙事：Hook → 项目背景 → 当前进展 → 产品展示 → 问题 → 下一步。

## 视觉规则

- 真实录屏、截图、提交记录优先；包装采用克制信息卡和轻运动。
- 缺少素材时使用明确占位，不生成假的代码、产品 UI 或用户反馈。
- 实拍项目必须先确认 A-roll 粗剪，再按粗剪时间线录制和映射产品操作。
- 人物矩形与圆形蒙版按内容段落切换；短暂抬头或低头不触发版式变化，同一版式建议至少保持 8–15 秒。
- 完整渲染前必须先制作包含人物、录屏、字幕和一次版式切换的 15–30 秒视觉样片。
- 默认不制作开头封面或结尾封面，前三秒直接进入 Hook；只有用户明确提出时才启用封面。

## 语言规则

- 第一人称、短句、像创业者复盘，不像发布会或广告。
- 区分事实、计划和假设。
- 采用自然偏快口语；内容说完即结束，不为凑整时长重复结论。
- 已有真实问题型 Hook 时直接使用，不强制生成固定数量的备选。

## 禁忌

- 禁止虚构用户、收入、融资、功能和效果。
- 禁止把预览语音冒充已接入的付费 provider。
- 禁止先锁死成片时长，再用机械长停顿或全局变速处理旁白。
- 禁止用上传转码文件替代手机原始 HDR 母版。
- 禁止让分段人物素材在每个场景重新从头播放。
- 禁止把 BGM 压入唯一一份发布母版。
- 默认禁止生成封面图或封面卡，避免占用黄金前三秒和引入额外版式返工。

## 标准路径

实拍个人 IP 视频执行 `立项 → 文案 → 原片检查与 HDR 转换 → A-roll 粗剪 → 按粗剪录产品操作 → Whisper 字幕 → 视觉样片 → 段落式包装 → 全片渲染 → QA → 发布素材包`。

完整检查点见 `docs/personal-ip-video-sop.md`。
